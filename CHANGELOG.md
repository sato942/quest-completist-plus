# Changelog

## 1.2.0 (2026-11-13)

- The quest window's title (accept, not-finished-yet, and hand-in pages) is drawn in the standard font, the same as the quest's text, so the level and the name match. New option "Quest title in the standard font", on by default; untick it to keep the game's ornate title font. The quest log is not changed.

## 1.1.0 (2026-11-13)

- First public version.
- New option, "Hide DialogKey's numbers" (game Options, AddOns, Quest Completist+), off by default. With it off, an NPC's quest list reads `1. [12] Quest Name`; with it on, `[12] Quest Name`. DialogKey's keys work either way.

## 1.0.0 (2026-11-13)

- Quest levels as `[12] Quest Name` on Quest Completist's map icon list, in an NPC's quest list (gossip window and quest greeting window), and in a single quest's window.
- Private build; always hid DialogKey's numbers.
